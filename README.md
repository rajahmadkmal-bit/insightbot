# InsightBot - Automated BI & Insights Agent

InsightBot is an AI-powered data analyst agent. It takes raw business data
(sales, marketing, customer data) and automatically cleans it, visualizes it,
and generates business insights — including answering natural language
questions about the data.

## Features
- Automated data cleaning (missing values, duplicates, type fixes)
- Smart chart selection based on column types (line, bar, pie, scatter)
- LLM-generated executive summaries in English or Urdu
- Natural language Q&A over your dataset (powered by LangChain)

## Tech Stack (100% free)
- Streamlit (UI)
- Pandas / NumPy (data handling)
- Plotly (visualization)
- LangChain + LangChain Experimental (agent orchestration)
- Google Gemini API (free tier LLM)
